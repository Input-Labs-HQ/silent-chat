# Google Chrome
- Go somewhere: key cmd+l, type a URL or search words, key return. New tab: cmd+t; reopen closed tab: cmd+shift+t.
- Tab N: cmd+1..cmd+9; next/previous tab: cmd+option+right/left. Back: cmd+[.
- Read a page or find a link/button on it: `ui "Google Chrome" --find <words>` (web content is listed as text, links, buttons).
- Find on page: cmd+f.

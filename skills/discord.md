# Discord
- Open any DM, channel or server: key cmd+k, type the person/channel name, wait 0.5, key return. No screenshot needed.
- After opening a DM, the message box has focus: type the draft. Return SENDS it (ask first); shift+return is a new line.
- Inbox (mentions and unreads): cmd+i. Mark a channel read: escape. Mark a server read: shift+escape.
- Next/previous channel: option+down/up; next unread: option+shift+down.
- Reading messages, DM names or notifications: `ui Discord --find <words>` or plain `ui Discord` (visible text is listed).
- All shortcuts: cmd+/.
- To put a window on the MacBook screen: leave full screen, then menu 'Window > Move to Built-in Retina Display', then full screen again.

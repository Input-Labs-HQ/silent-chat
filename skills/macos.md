# macOS (any app)
- Find shortcuts instead of clicking: `menu <App> <Menu>` lists a menu's items with their shortcuts.
- Spotlight: key cmd+space, type the name, key return (opens apps, files, settings panes).
- Common: cmd+n new, cmd+t new tab, cmd+w close tab/window, cmd+f find, cmd+, settings, cmd+z undo, cmd+s save.
- Save/Open dialogs: key cmd+shift+g, type a folder path, key return; then set the file name field and press Save.
- Text fields: cmd+a select all, option+delete deletes a word, cmd+left/right start/end of line.
- Switch apps with `focus <App>` (more reliable than cmd+tab).
